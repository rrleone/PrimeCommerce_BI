## Visão geral do projeto

![PrimeCommerce BI — Visão geral do projeto](05_Portfolio/PrimeCommerce_BI.png)

O **PrimeCommerce BI** é um projeto de Business Intelligence voltado à análise comercial de um e-commerce fictício.

O objetivo é transformar dados operacionais em informações gerenciais que permitam compreender o desempenho das vendas, acompanhar indicadores comerciais e identificar oportunidades de melhoria.

O projeto contempla preparação e transformação dos dados, modelagem analítica, desenvolvimento de medidas e construção de dashboards interativos no Power BI.

## Problema de negócio e objetivos

A gestão de um e-commerce precisa acompanhar o desempenho comercial e compreender como o faturamento, os pedidos, os produtos, os vendedores e os canais contribuem para os resultados.

O projeto busca responder questões como:

- Qual é o faturamento total e como ele evolui ao longo do tempo?
- Como se comportam o volume de pedidos e o ticket médio?
- Quais categorias e produtos apresentam maior participação comercial?
- Como se distribuem os resultados entre vendedores e canais de venda?
- Quais regiões apresentam maior concentração de clientes?
- Como os indicadores podem apoiar decisões comerciais?

## Processo de desenvolvimento

O projeto segue um fluxo de trabalho de Business Intelligence:

**Dados → Preparação → Modelagem → Indicadores → Visualização → Insights**

### Preparação e transformação dos dados

- Inspeção e compreensão da estrutura dos dados.
- Tratamento e organização das informações.
- Preparação das tabelas para análise.
- Aplicação de transformações necessárias para o modelo analítico.

### Modelagem de dados

- Organização das entidades comerciais.
- Construção dos relacionamentos entre tabelas.
- Estruturação do modelo para análise de vendas.
- Preparação da base para criação dos indicadores.

### Indicadores e análises

- Faturamento total.
- Quantidade de pedidos.
- Itens vendidos.
- Ticket médio.
- Lucro bruto.
- Análise temporal.
- Desempenho por categoria, vendedor e canal.
